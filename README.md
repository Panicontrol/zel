# Blade Prototype

2D-платформер на Godot 4.7 (GDScript). Ассеты генерируются в ComfyUI.

## Запуск

1. Установите [Godot 4.7](https://godotengine.org/download) (обычная версия, не .NET).
2. В Project Manager нажмите **Import** и выберите `project.godot` из этой папки.
3. Нажмите **F5** (Run Project).

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Ходьба | A / D или ← / → | Левый стик, крестовина |
| Прыжок | Пробел, W или ↑ | A (Xbox) / ✕ (PS) |

Короткое нажатие прыжка — низкий прыжок, удержание — высокий (чуть выше 3 тайлов).
Прыжок срабатывает ещё 0,1 с после схода с края и засчитывается, если нажать его чуть раньше приземления.

## Структура

| Путь | Что там |
| --- | --- |
| `project.godot` | Настройки проекта: базовое разрешение 1920×1080, рендер Compatibility |
| `scenes/main.tscn` | Главная сцена: уровень + камера |
| `scenes/player.tscn` | Герой: тело с коллизией + `AnimatedSprite2D` |
| `scripts/player.gd` | Управление героем и выбор анимации |
| `scripts/level.gd` | Строит уровень из ASCII-карты, генерирует тайлсет-заглушку |
| `scripts/parallax_layers.gd` | Параллакс-слои окружения |
| `levels/level_01.gd` | Карта уровня: один символ = тайл 64×64 (`#` — камень, `P` — старт героя, `.` — пусто) |
| `assets/hero/` | Кадры анимаций героя (сейчас — заглушки) |
| `assets/levels/level_01/` | Картинки окружения уровня (сейчас — заглушки) |

## Ассеты из ComfyUI

Базовое разрешение — **1920×1080**, камера без увеличения: 1 пиксель картинки = 1 пиксель
экрана в Full HD. На других разрешениях всё масштабируется целиком.

### Окружение (фоны)

Картинки окружения уровня кладутся в `assets/levels/level_01/`:

| Файл | Что это | Скорость (параллакс) |
| --- | --- | --- |
| `layer_0.png` | Небо — стоит на месте | 0 |
| `layer_1.png` | Дальний план (горы) | 0.1 |
| `layer_2.png` | Средний план (холмы, башни) | 0.25 |
| `layer_3.png` | Ближний план (лес) | 0.5 |
| `foreground.png` | Передний план **перед** героем (ветки, колонны) | 1.3 |

Скорость: 0 — слой прибит к экрану, 1 — движется вместе с уровнем, больше 1 — передний план.
Список слоёв и скорости — `PARALLAX` в `levels/level_01.gd`: можно переименовать, добавить
или убрать слои. Отсутствующие файлы пропускаются.

Требования к картинкам:
- ширина **1920** (или больше), высота **1080** (или больше);
- слой повторяется по горизонтали — левый и правый край должны **бесшовно** стыковаться
  (в ComfyUI: seamless/tiling по X или outpaint краёв);
- все слои, кроме неба, — PNG с **прозрачным** верхом;
- нижний край картинки совпадает с низом экрана, когда камера в самом низу уровня;
  выше верхнего края виден фон неба, поэтому для высоких уровней делайте картинки выше 1080.

### Герой

Анимация покадровая, без костей. Каждая анимация — горизонтальная лента квадратных
кадров в `assets/hero/`:

| Файл | Кадров сейчас | Скорость |
| --- | --- | --- |
| `idle.png` | 4 | 6 кадр/с, по кругу |
| `walk.png` | 8 | 12 кадр/с, по кругу |
| `jump.png` | 1 | — |
| `fall.png` | 1 | — |

Правила для замены кадров:
- кадр квадратный, число кадров = ширина / высота — можно положить ленту с любым числом кадров;
- герой смотрит **вправо** (влево отражается автоматически);
- ноги касаются **нижнего края** кадра, по центру по горизонтали;
- прозрачный фон;
- сейчас кадр 128×128, герой ~110 px ростом (коллизия 36×92). Если кадры будут другого
  размера — поменяйте `position` (минус половина высоты кадра) и при необходимости `scale`
  у узла `Sprite` в `scenes/player.tscn`.

Скорость анимаций — словарь `ANIMATIONS` в начале `scripts/player.gd`.

### Тайлы

Если положить `assets/tiles/tileset.png` (тайл камня 64×64), уровень возьмёт его
вместо процедурной заглушки.
