# Blade Prototype

2D-платформер на Godot 4.7 (GDScript). Ассеты генерируются в ComfyUI.

## Запуск

1. Установите [Godot 4.7](https://godotengine.org/download) (обычная версия, не .NET).
2. В Project Manager нажмите **Import** и выберите `project.godot` из этой папки.
3. Нажмите **F5** (Run Project).

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Ходьба | A / D или ← / → | Левый стик, крестовина |
| Прыжок | Пробел, W или ↑ | A (Xbox) / ✕ (PS) |

Короткое нажатие прыжка — низкий прыжок, удержание — высокий (до 3 тайлов).
Прыжок срабатывает ещё 0,1 с после схода с края и засчитывается, если нажать его чуть раньше приземления.

## Структура

| Путь | Что там |
| --- | --- |
| `project.godot` | Настройки проекта: окно 1280×720, рендер Compatibility |
| `scenes/main.tscn` | Главная сцена: уровень + камера |
| `scenes/player.tscn` | Герой: тело с коллизией + `AnimatedSprite2D` |
| `scripts/player.gd` | Управление героем и выбор анимации |
| `scripts/level.gd` | Строит уровень из ASCII-карты, генерирует тайлсет-заглушку |
| `levels/level_01.gd` | Карта уровня: один символ = тайл 32×32 (`#` — камень, `P` — старт героя, `.` — пусто) |
| `assets/hero/` | Кадры анимаций героя (сейчас — заглушки) |

## Ассеты из ComfyUI

### Герой

Анимация покадровая, без костей. Каждая анимация — горизонтальная лента квадратных
кадров в `assets/hero/`:

| Файл | Кадров сейчас | Скорость |
| --- | --- | --- |
| `idle.png` | 4 | 6 кадр/с, по кругу |
| `walk.png` | 8 | 12 кадр/с, по кругу |
| `jump.png` | 1 | — |
| `fall.png` | 1 | — |

Правила для замены кадров:
- кадр квадратный, число кадров = ширина / высота — можно положить ленту с любым числом кадров;
- герой смотрит **вправо** (влево отражается автоматически);
- ноги касаются **нижнего края** кадра, по центру по горизонтали;
- прозрачный фон;
- сейчас кадр 64×64 и герой ~53 px ростом. Если кадры будут крупнее — поменяйте
  `position` и `scale` у узла `Sprite` в `scenes/player.tscn`.

Скорость анимаций — словарь `ANIMATIONS` в начале `scripts/player.gd`.

### Тайлы

Если положить `assets/tiles/tileset.png` (тайл камня 32×32), уровень возьмёт его
вместо процедурной заглушки.
